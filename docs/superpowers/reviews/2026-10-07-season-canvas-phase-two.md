# 시즌 캔버스 2단계 구현·검증 기록

검증일: 2026-10-07

기준: [백엔드 2단계 연동 지침](../../../../backend/docs/frontend/season-canvas-phase-two.md), [구현 계획](../plans/2026-10-07-season-canvas-phase-two.md).

## 구현 결과

목록과 상세의 관람 링크가 `/season-canvas/:seasonId`를 연다. 로그인 사용자는 active 시즌에 참가하며, 본문 없는 쿠키 포함 POST의 성공 결과로 상세 캐시를 교체한다. 기존 연결을 폐기하고 새 ready와 sync를 받은 뒤 그리기를 허용한다. 익명 사용자와 쓰기 권한이 없는 연결은 관람을 유지한다.

메인과 시즌의 연결·동기화·그리기는 `features/canvas-workspace`가 공유한다. 메인의 handshake와 10000×10000 크기, 계정당 한 획 정책은 유지한다. 시즌은 ready의 크기와 서버의 사용량 판정을 사용한다. 화면에 남은 획 수를 추정해 표시하지 않는다. 로컬 연습은 서버 append를 보내지 않는다.

종료 이벤트는 입력과 미확정 입력을 닫고 이벤트 head까지 복구한다. 경계 이하의 늦은 preview와 저장된 부분 획을 유지한다. 재연결 시 epoch가 바뀌면 이전 그림·cursor·미확정 전송 대기를 비우고 새 stream으로 복구한다. 참가·세션 변경·상태 갱신에서 이전 HTTP 응답과 소켓 binding을 사용하지 않는다.

append는 초당 최대 30회, sync는 최대 5회로 제한한다. 이벤트별 ACK 요청을 직렬화한다. 페이지 복구 중 방송은 버퍼에 남기며 첫 페이지 head를 고정한다. 용량·일시 장애 재시도는 동일 cursor·head 또는 append 묶음을 보존한다.

## 브라우저 검증

Vite 개발 서버 `http://localhost:5174`에서 Playwright CLI로 검증했다. 제품 코드 외부의 HTTP·Socket.IO 테스트 응답을 사용했다. fixtures와 스크린샷은 `/private/tmp/season-two-*`에 두었으며 제품 번들에 포함하지 않는다. 실제 백엔드·DB·지갑 인증을 검증한 결과는 아니다.

- 관람 링크, 참가 버튼, 팔레트와 모드 전환, 제한 오류, 상세 오류 재시도, 로딩, 취소 접근 차단, 잘못된 UUID의 handshake 0회를 확인했다.
- 360×640, 390×844, 1280×720, 1440×900에서 가로 넘침이 없었다. 모바일 도구·상태 패널은 내부 스크롤을 유지하고 캔버스 높이를 확보한다.
- 종료 후 새 입력은 append를 보내지 않았다. 종료 head 복구 뒤 epoch를 바꿔 재연결해 부분 획의 재표시를 확인했다.
- 메인 화면의 10000×10000 캔버스, 기존 handshake, 연습 모드 전송 0회와 레이아웃을 확인했다.
- 개발 중 hook 구조 변경에 따른 HMR 오류는 새로 로드한 화면에서 재현되지 않았다. 기존 React script 태그 경고는 남아 있다. 테스트에서 의도한 HTTP 401·404·503도 콘솔에 기록된다.

## 코드 리뷰에서 수정한 문제

- 최초 HTTP 상세가 ready보다 늦거나 먼저 도착해도 상태 불일치를 대조한다. 이미 종료 이벤트의 head를 복구 중이면 재연결로 중단하지 않는다.
- 시즌의 `STROKE_ALREADY_USED`는 해당 획 ID 복구를 수행한다. 계정 전체 한도 도달로 취급하지 않으며 복구 뒤 다음 획을 허용한다.
- sync의 `CANVAS_CAPACITY_REACHED`도 고정 head·cursor를 보존하고 1초 뒤 재시도한다.

별도 코드 리뷰에서 추가 high/medium 결함은 발견되지 않았다. 관련 회귀 테스트를 추가했다.

## 완료 검사

`npm run format:check`, `npm run lint`, `npm test`, `npm run build`가 모두 통과했다. 전체 테스트는 31개 파일, 205개 테스트다. `git diff --check`도 통과했다. 실환경 검증은 위 표의 서버 확인 범위로 남긴다. 커밋과 배포는 수행하지 않았다.
